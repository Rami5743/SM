static variblas:
Stored in registers 16-255. have names which are symbols, recognased by all the code. if you want that the names will be recognize by the file/function only use names filename.xxx/filename.functionname.xxx. otherwithe do not use ".". the varibles maintain thire value after the function is done.

-> @integer
pop to the regester with relative address "integer" from the stack

-> symbol
pop to a static varible with name "symbol" from the stack

<- @integer
push  the regester with relative address "integer" to the stack

<- integer
push the constant "integer" from the stack

<- symbol
push the value of a static varible with name "symbol" to the stack

[integer]
replace the top element in the stack x by the content of regester with absolut adress x+"integer" 

->[integer]
eliminate the top 2 element in the stack x,y and put x in regester with absolut adress y+"integer"
